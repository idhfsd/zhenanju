# 震安居 · 部署上线指南（怎么把网站变成一个可访问的地址）

> 当前代码已改造为「前后端同源、只暴露一个端口」：Express 同时提供 `/api` 接口和 Vue 的静态页面。
> 因此下面所有方案只需要部署**一个服务**，不用再单独托管前端。

---

## 方案一：内网穿透（最快，5 分钟，适合课堂演示）

不需要买服务器，把你电脑上的 3000 端口临时映射成公网 https 地址。

### 1. 安装 ngrok

```bash
# 先注册 https://ngrok.com 拿 authtoken
winget install ngrok.ngrok     # 或用官网下载 exe
ngrok config add-authtoken <你的 token>
```

### 2. 启动（两个终端）

```bash
# 终端 1
cd D:\Doubao\chats\2026-10-25\new-chat-3\zhenanju-server
npm start

# 终端 2
ngrok http 3000
```

### 3. 拿到地址

```
Forwarding  https://xxxx-xx-xx.ngrok-free.app -> http://localhost:3000
```

这个地址直接发给同学/老师就能打开，接口也是同一个地址（因为前端请求是相对路径 `/api`）。

**注意**
- 电脑必须保持开机、服务保持运行，关了就失效
- 免费版地址每次重启都会变
- 国内访问 ngrok 可能不稳定，可换 cpolar（国内）、花生壳、frp

## 方案二：免费云平台（不用买服务器，给固定 https 域名）

适用：Render / Railway / Zeabur（这三家都支持直接跑 Node 服务，不需要改代码）。

### 步骤

1. 把项目推到 GitHub（**不要提交 node_modules**，.gitignore 里加一行）
2. 平台里新建服务 → 选 GitHub 仓库
3. 填配置：

| 配置项 | 值 |
|---|---|
| Root Directory | `zhenanju-server` |
| Build Command | `cd ../zhenanju-vue && npm install && npm run build && cd ../zhenanju-server && npm install` |
| Start Command | `node index.js` |
| 环境变量 PORT | 平台会自动注入，代码已用 `process.env.PORT` 兼容 |

> 也可以先在本地 `npm run build`，把 `dist` 一起提交，省掉构建步骤。

4. 部署完拿到类似 `https://zhenanju.onrender.com` 的地址

**注意**
- Render 免费实例 15 分钟无访问会休眠，再次打开要等 30 秒左右
- 免费平台的域名在国内访问速度一般
- `data/*.json` 这类文件在多数平台重启后会丢（容器文件系统不持久），要持久化得换成数据库

## 方案三：国内云服务器 + 域名（长期可用，小程序真机必需）

### 何时必须走这条

微信小程序**真机预览 / 提审发布**时，请求域名必须：
1. `https` 协议
2. 域名已完成 **ICP 备案**
3. 在小程序后台「开发管理 → 服务器域名 → request 合法域名」里配置

免费平台的域名（onrender.com 等）不能备案，所以**小程序真机只能走国内云服务器 + 备案域名**。

### 步骤

1. 买学生机（阿里云/腾讯云，几十元一年），系统选 Ubuntu
2. 域名解析到服务器 IP，完成备案（约 1~3 周，提前办）
3. 服务器上装 Node 18+，把项目传上去（scp 或 git clone）
4. `npm install && cd ../zhenanju-vue && npm install && npm run build`
5. 装 Nginx，反向代理到 3000，配置 https（Let's Encrypt 免费证书）：

```nginx
server {
    listen 443 ssl;
    server_name zhenanju.yourdomain.com;

    ssl_certificate     /etc/letsencrypt/live/zhenanju.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/zhenanju.yourdomain.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

6. 用 pm2 让服务常驻：

```bash
npm i -g pm2
pm2 start index.js --name zhenanju
pm2 save && pm2 startup
```

## 方案四：微信小程序「云托管」（不想备案又想上真机的话）

微信官方提供 CloudBase 云托管，可以直接跑 Node 容器，平台给一个默认域名，**可加入小程序 request 合法域名且无需备案**。

- 控制台：微信公众平台 → 开发 → 云开发 → 云托管
- 上传：项目根目录放 `Dockerfile`：

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY zhenanju-server ./zhenanju-server
COPY zhenanju-vue/dist ./zhenanju-vue/dist
WORKDIR /app/zhenanju-server
RUN npm install --omit=dev
EXPOSE 3000
CMD ["node", "index.js"]
```

- 部署后拿到云托管域名，填到小程序后台合法域名即可

## 部署前自查清单

- [ ] `npm run build` 能成功产出 `zhenanju-vue/dist`
- [ ] 直接访问 `http://localhost:3000/` 能打开整站（说明同源托管生效）
- [ ] `http://localhost:3000/api/monitor/stats` 返回 JSON
- [ ] 后端端口用 `process.env.PORT || 3000`，不要写死（云平台会注入随机端口）
- [ ] 生产环境把 `cors()` 收紧为只允许自己的域名（同源部署其实可以关掉 cors）
- [ ] JSON 文件「数据库」只适合演示；多人并发写入会丢数据，正式用要换 MySQL/SQLite

## 一个地址能做什么（当前已实现）

| 地址 | 内容 |
|---|---|
| `https://你的域名/` | 震安居首页 |
| `https://你的域名/#/monitor` | 监测平台（数据来自同域 /api） |
| `https://你的域名/#/contact` | 联系我们（表单可提交） |
| `https://你的域名/api/monitor/stats` | 接口，可直接浏览器打开验证 |
